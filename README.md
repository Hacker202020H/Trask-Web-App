# 🛰️ Trask-Tech - Professional IT Solutions & Software Development

A modern, responsive promotional website for Trask-Tech, a leading provider of professional IT solutions and software development services.

## 📋 Overview

Trask-Tech is a sophisticated, multi-page website showcasing comprehensive IT services and expertise. Built with HTML, CSS, and JavaScript, the site features stunning animations, modern design patterns, and professional branding suitable for a high-tech development company.

## 🌐 Website Structure

### Pages

1. **Home (Index.html)** - Landing page with hero section and service overview
   - Professional hero banner
   - Service highlights
   - Call-to-action section
   - Contact CTA

2. **About (about.html)** - Company information and team expertise
   - Core values and mission
   - Team expertise showcase
   - Professional experience highlights
   - Why Choose Us section

3. **Services (services.html)** - Comprehensive service offerings
   - 6 main service categories
   - Detailed service descriptions with features
   - Pricing tiers (Startup, Professional, Enterprise)
   - Service packages and benefits

4. **IT Information (it-info.html)** - Educational content about IT topics
   - IT industry insights
   - Educational articles
   - Technology information and guidance
   - Best practices

5. **Contact (contact.html)** - Contact and inquiry page
   - Contact form
   - Multiple contact methods
   - Contact information cards
   - Email, WhatsApp, and location details

## 🚀 Getting Started

### Prerequisites

- Any modern web browser (Chrome, Firefox, Edge, Safari)
- No server or build tools required

### Running the Website

1. Clone or download the project files
2. Open `Index.html` in your web browser
3. Navigate through the pages using the menu

**Or run in Firefox (VS Code Debug):**
- Use the configured `launch.json` to open the site in Firefox
- Press `F5` to debug
